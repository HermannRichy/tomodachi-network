# Button

Bouton à relief marqué, qui s'enfonce de 4px à l'appui.

- **Plein `primary`** : l'action principale de l'écran, une seule par écran.
- **Plein `sakura`** : action communautaire forte (guild, watch party).
- **Secondaire** : fond `surface`, bordure `border-width` en `border`, relief en `border-depth`, texte `primary`.
- **Icône** : carré de 52px, `aria-label` obligatoire.

Hauteur 52px, rayon `radius-lg`, style de texte `button`, relief `depth-md` dans la couleur `-depth` correspondante. À l'appui : le relief passe à 0 et le bouton descend de `depth-md`. Libellés à l'impératif, en deux à quatre mots.
