# Card

Conteneur à relief pour les publications, sections de profil et blocs de guild.

Fond `surface`, bordure `border-width` en `border`, bord inférieur `depth-md` en `border-depth`, rayon `radius-lg`, padding `space-4`, écart interne `space-3`. Une carte ne contient qu'un sujet. Les cartes ne s'imbriquent pas : à l'intérieur, utiliser des fonds teintés (`-soft`) plutôt qu'une seconde bordure.
