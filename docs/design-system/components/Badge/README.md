# Badge

Étiquette courte pour un niveau, un titre, un statut ou une annonce officielle.

Style de texte `label`, rayon `radius-sm`. Toujours un fond `-soft` avec son texte `-ink`, sauf « Officiel » qui prend `gold` plein avec `on-gold`. Couleur par sens : `gold` pour niveaux et récompenses, `primary` pour les titres, `sakura` pour le temps et la guild, `success` pour les statuts positifs. Trois mots maximum.
