# TabBar

Barre de navigation du bas : Accueil, Messages, Publier, Guild, Profil.

Fond `surface`, bordure supérieure `border-width` en `border`. Icônes Phosphor Bold 24px avec libellé `label` en dessous. Onglet actif : fond `primary-soft`, texte `primary-ink`, icône en graisse Fill. Au centre, le bouton Publier est un bouton plein `primary` à relief, avec `aria-label`. Cinq entrées maximum, cibles de 52px de haut.
