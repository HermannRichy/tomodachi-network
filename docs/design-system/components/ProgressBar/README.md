# ProgressBar

Barre de progression arrondie ; sa couleur dit ce qui progresse.

- **EXP et niveaux** : remplissage `gold` sur piste `primary-depth`, dans un panneau `primary`.
- **Visionnage** : remplissage `success` sur piste `success-soft`, hauteur 8px.
- **Guilds et défis** : remplissage `sakura` sur piste `sakura-soft`.

Hauteur 14px par défaut, rayon `radius-pill`. Toujours accompagnée de sa valeur en texte (« ép. 8 / 24 »), jamais seule. Chiffres en `tabular-nums`.
